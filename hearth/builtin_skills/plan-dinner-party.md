---
name: Plan a dinner party
description: Plan a guest-aware dinner menu and make an Excel shopping list.
when_to_use: The user wants to plan or host a dinner party, including its menu and groceries.
tools: [memory_search, memory_read, create_spreadsheet]
---
1. Find the guests' known allergies and dietary needs in memory. Use named guest notes when available. Cite the memory you rely on. Ask about missing constraints and never infer that a guest has no allergies.
2. Plan a menu for the headcount, preferences, and timing. Call out shared dishes that need allergy precautions. Label assumptions and suggest confirming restrictions before shopping.
3. Use `create_spreadsheet` for an Excel shopping list unless the user asks to skip it. Group groceries by section and give each item a quantity and unit. Link the workbook by presenting the resulting artifact in chat.
