# Hearth product brief

Hearth is a personal agent for Fly.io Hacksgiving 2026. It runs as a private workspace on a Fly.io Sprite and uses Sprites connectors to reach authorized external services.

## Workspace

- Chat with Ember in Main or a side chat, attach files, and follow the agent's actions in Timeline.
- Keep personal context in Markdown and use connected semantic recall when available.
- Review sensitive proposed actions before execution. Restore supported item changes or use a filesystem checkpoint when the action calls for one.
- Create artifacts and HTML pages, receive reminders, and schedule prompts with a persisted run history.
